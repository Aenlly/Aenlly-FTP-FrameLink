# 0.1.23原片预览缓存与正式导入

“查看原片”从相机读取当前JPEG，进入App可清理缓存。它不写入系统相册，不生成导入任务，不修改照片文件的localUri／originalPath、已导入状态或待下载数量。RAW沿用原有预览和导入入口。

原片级预览上限约2GiB，优先清理较旧缓存；设置中的清理预览缓存同时清除缩略图和JPEG原片预览，不删除正式导入文件或选片记录。预览完成后记录SHA256，未完成的缓存不对外提供。

正式导入JPEG时，以照片资源身份和文件元数据匹配缓存，流式复制到正式文件暂存区并重新计算SHA256；长度和摘要一致才发布为已导入。缺失、资源不匹配或校验失败则回到相机读取，RAW不使用JPEG缓存。正式导入的状态和任务更新沿用原有流程。

放大仍使用原片可见区域解码，预览到位不关闭大图，也不把缓存标为已导入。
