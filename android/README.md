# 光屿 FrameLink Android

包名`app.framelink.camera`，最低Android 8.0/API26，当前提供arm64和x86_64原生协议库

## 构建

在工程根目录运行：

```sh
python3 scripts/bootstrap.py
sh scripts/build-android.sh
```

生成`artifacts/FrameLink-0.1.1-debug.apk`。这是Android开发证书签名的测试包，正式签名、商店提交与公开发布是独立步骤

## 连接相机

第一批目标是Sony A7C II。先让手机与相机处于同一局域网，或在手机Wi-Fi设置中连接相机的直连网络

1. 在机身开启PC远程，查看PC远程Wi-Fi连接信息
2. 打开机身网络选项中的访问认证信息
3. 在App“连接相机”中填写IP、账号、密码和机身显示的SHA256指纹
4. 连接后根据相机返回的能力浏览、下载、取景和调整参数

开启访问认证时必须提供指纹；机身关闭访问认证时账号留空。App只为相机socket绑定局域网，不改变云端请求的默认网络。部分手机连接无互联网Wi-Fi时需要在系统提示中选择保留连接

## 边拍边传

在手机打开热点，或让手机和相机加入同一个可信局域网。在首页“FTP 接收”中选择手机实际地址并启动接收，机身FTP配置填写该地址、App中设置的端口（默认2121）、账号和接收密码，使用被动模式和UTF-8文件名

自动发送、保护照片发送、RAW/JPEG目标由机身设置。FTP服务只接收，不提供原片下载、删除或重命名命令。原片落盘及任务保存之后才回复226；预览与系统相册处理另行排队。失败上传需要相机重新发送

“保存位置与压缩副本”支持选择系统授权文件夹、单独的压缩副本目录、尺寸和JPEG质量、格式范围及是否同步副本到相册。原文件保留。配置和账号加密保存，不要求云端登录

## FTP客户端

首页点击“FTP 客户端”，填写服务器地址、端口、账号、密码和起始目录；默认被动模式，可选择UTF-8、GBK或ISO-8859-1文件名编码。支持显式FTPS并验证服务器证书，不支持隐式FTPS或SFTP

连接后可进入目录、返回上级、搜索当前目录、刷新、新建文件夹。选择文件并点击底部下载，或通过“上传文件”选择系统文件；任务进度、取消和重试在底部“传输”中查看。FTP入口在传输页也可直接打开

下载的照片加入“图库→已导入”；其他文件在传输任务中打开、分享或另存。上传同名文件会拒绝覆盖，需在系统文件管理器中为本地文件改名后重新选择。重试从头传输，不宣称断点续传

账号加密保存在本机，可在最近连接中移除。FTP客户端下载和接收端共用保存目录与压缩副本设置。普通FTP不加密，建议仅在可信局域网使用，服务器支持时开启FTPS

## 蓝牙快捷快门

在机身开启蓝牙遥控和配对模式，授权App蓝牙权限后选择相机。快门遵循机身当前单拍或连拍设置，界面区分指令确认和实际拍摄结果

## 云端选片

本地使用无需登录。可选云端服务见`cloud/README.md`。Android设置页填写服务地址、邀请注册或登录摄影师账号。公开服务要求HTTPS，开发环境允许局域网HTTP

在图库选择照片加入项目，仅生成并上传预览副本。客户确认后，摄影师可为已选照片关联成片。默认等待非计费网络，移动网络上传由用户主动开启

## 验证边界

模拟器及模拟协议验收不代表A7C II实体机兼容。目标机身固件、无线稳定性、蓝牙、HEIF/RAW预览、真实吞吐和耗电需按`docs/IMPLEMENTATION.md`独立记录
