# 照片信息

Android沿用ExifInterface；iOS0.1.9使用系统ImageIO，展示ISO、快门、光圈、焦距、等效焦距、曝光补偿、镜头、机型、拍摄时间、像素尺寸、GPS、海拔及坐标基准。iOS仅在当前页保留高清图，缓存和信息来源明确标识；界面与iPhone实测尚未完成，见[本轮验收](acceptance/2026-10-31-ios-preview-exif-0.1.9.md)。以下可展开的更多字段描述为Android范围。

iOS0.1.10仅在曝光时长接近整数倒数时显示1/N，0.8、0.6、0.4、0.3秒等保留实际小数；信息页按最新文件路径和来源重新读取，不因打开信息页自动下载。

大图点“文件信息”，在“原始文件”页查看这张照片的拍摄记录。ISO、快门速度、光圈优先展示；焦距、曝光补偿、镜头、机型、拍摄时间和像素尺寸随后显示。曝光模式、白平衡、测光、闪光、等效焦距、处理软件及存在的作者／版权记录可展开查看。

读取顺序为已导入的非RAW文件、JPEG原片临时缓存、已导入RAW、已有预览副本。选择同一份文件的EXIF，不把机身当前设置当作照片拍摄参数。JPEG缺失字段显示未提供；只有预览副本时，可主动读取JPEG完整信息，仍走2GiB临时缓存，不创建导入任务。

GPS只来自照片。照片没有记录完整坐标时不使用手机位置，也不把0°纬度／经度当成缺失。有坐标可显示海拔、坐标基准，并通过标准geo链接打开地图；未识别的坐标基准只显示原值，不按WGS84盲目定位。本版不自动反查街道地址，不请求手机定位权限。

解析沿用项目已有AndroidX ExifInterface，不改变原片字节、选片结果或导入标记。RAW／HEIF是否能读取取决于格式与文件实际携带的EXIF，不能由JPEG测试推导所有格式兼容。索尼私有MakerNote风格等未解码字段不使用当前机身状态代填。
