# 实施与验收报告

版本：Android0.1.14／iOS0.1.6开发预览。Android、iOS、相机协议与本地选片的源码、软件测试和真机结果分别记录；本文件不代表已完成正式发布。

Android0.1.14增加图库侧边导航、按内容宽度计算的网格、大图双栏与响应式对比。窗口变化保留照片和选择，保存选片弹层在键盘和缩窗下保持可操作。独立API35模拟器验证七种尺寸／字体、横竖屏状态以及真实自由窗口缩放，实际系统双应用分屏与平板真机待验，见[图库窗口适配](TABLET_GALLERY.md)。

后续按已确认的v5继续落地相机、项目、传输和取景界面；常驻参数保留f／S／ISO／EV／WB／AF，展开菜单继续中文。设计基准SHA256为`45f4423e1bcc452df7fabd3d601d4e7390d92796601c6d5fac1a021c094b4096`。界面阶段结束后推进佳能EOS850D、富士X-T30 II及索尼ILCE-7M4／7M5／6700的协议适配，保留ILCE-7CM2现有路径；新增机型目前不能视为已接通或已实测。

Android0.1.13接入新版手机图库：浏览与选择分开，筛选和网格密度收进菜单，支持双指调整密度、长按范围滑选及分页全选。大图支持翻页、缩略条和统一选择，保留分享、修图副本与本地移除。导入和完成后保留本次选择；相机断开隐藏在线列表，草稿重连后按资源信息核对。详见[图库操作](GALLERY_BROWSING.md)。本轮未更换相机首页、项目和传输页；平板侧栏、双栏及独立验收继续安排，iOS保持0.1.6。

0.1.5增加系统相机式竖屏操作区、独立专业工具面板、已配对相机直接重连和失败回退设置；图库加入小／中／大图与列表，分别显示JPEG、RAW、HEIF及其导入状态。主取景页不常驻协议型号和分辨率，技术信息放入连接详情。两端使用新的相机／相片连接图标，来源与提示词见design/brand/ICON.md。

0.1.6升级编译与目标版本到Android17/API37，增加局域网权限流程。取景保持旋转时的同一窗口和菜单状态，横屏参数与快门分置两侧黑边，专业工具收为窄侧栏，直方图成为可关闭的角落参考图。图库采用5／3／2列与列表、蓝色圆勾，支持按当前范围全选、分页补齐和取消，修正重连后的空白列表，更新浮动导航。FTP增加复制配置、固定启动入口、登录状态与已接收照片入口。iOS提供需要自行签名的设备IPA，见ios/INSTALL.md。

## 本轮改动

Android0.1.12以苹果相机的简洁层级为主，吸收小米专业模式的参数刻度交互。默认拍照页保留快门、相册和少量控制；专业模式再显示机身参数。横屏把控制集中到右侧，竖屏使用底部模式胶囊，开关菜单和模式不挤动原比例取景。参数尺停稳后仅提交一次，并读回机身实际值；更多工具使用六项图标菜单。详见[取景交互](CAMERA_UI.md)。

Android0.1.11将横屏快门、相册和曝光参数固定在两侧留边。专业参数使用左侧窄区，展开不缩小取景，直方图保持角落小图。Android0.1.10将自动导入开关同步为机身保存目的地，并在拍摄前读回确认，提供不触发快门的待传文件接收入口。红米实收约29.5帧/秒、网络往返平均10.4毫秒，机身仅存卡、待传为0；这些指标不等于端到端视觉延迟。

Android0.1.9补上远程选点后的AF半按与释放，保持机身的对焦区域模式；快速连续点按只保留最后一个待处理位置。增加只读拍摄状态和前后景预览采样诊断。0.1.8实拍已验证单张、约1.8秒恢复与相册保持连接；实际合焦未通过，0.1.9继续用前后杯子场景核对。

Android0.1.8将快门与拍后文件接收分开，默认不自动导入；单张模式核对并临时切换机身驱动，释放成功后恢复，异常时不自动重拍。点按画面用于对焦，沉浸菜单通过独立按钮展开。左侧相册固定进入相机图库，并等拍摄操作完成后再读取。详见[拍摄与对焦](CAPTURE_AND_FOCUS.md)。

Android0.1.7修正红米Android13全屏测量、相机目录先旧后新的分页和末页仍显示加载入口的问题。按当前日期先读取元数据快照，最新照片从第一页可见；滑到底自动补齐，结束与失败分开显示。iOS0.1.6未接入本轮目录加载改动。见[相机选片与加载](GALLERY_BROWSING.md)和[全屏兼容](ANDROID_13_FULLSCREEN.md)。

iOS原片以文件路径传过桥，导入和摘要以256KiB分块进行，预览采样解码。索引使用原子JSON保存，相机密码与受信任指纹使用Keychain。后台停止取景和FTP服务；运行中的任务在下次启动显示中断，避免假装后台仍在线。

Go FTP模块供iOS使用，Android继续使用原有Apache实现。接收只提供上传，唯一文件与回执落盘后回复成功；客户端支持被动模式、UTF-8、显式FTPS验证、上传临时文件与同名检查。标准FTP不能提供跨客户端的原子禁止覆盖，需服务器权限配合。

## 软件检查

Android0.1.12滑块候选：JVM23项与整轮安装回归32项通过；亮暗背景各采集八种状态，主包与诊断包散列一致，均为API35独立模拟器。取景专项覆盖拖动后提交与回读、参数回退、菜单触摸不穿透、旋转、完整构图、快门与底部手势区边界。真实手机和镜头动作仍按构建单独验收。

Android0.1.11：JVM23项、安装回归31项通过，包含横屏留边控制、64dp参数带、真实候选值的切换与恢复、旋转不重建窗口及预览尺寸保持。拍摄状态更新移至主线程，相机与文件操作保留在IO线程。Go桥26项既有通过记录覆盖当前对焦和保存策略；本轮没有修改iOS、云端或客户网页业务代码。

完整日志位于本机忽略目录build-logs，冻结清单记录最终检查时间。失败尝试保留，不用截取日志末尾代替退出状态。

Android0.1.7取得JVM21项、安装回归31项、Go桥18项通过记录，增加250张照片的自动分页、稳定倒序、全选与末页检查，以及刚好100／200张时不产生虚假下一页的边界测试。iOS0.1.6保留Swift核心6项XCTest及14条核心检查、安装交互5项的既有通过记录；最终状态以冻结清单为准。

Android0.1.8增加对焦坐标单元测试，JVM共23项；Go桥共22项，覆盖单张模式恢复、快门不重发、仅电脑保存保护和点按对焦不触发全按快门。31项安装回归通过后，针对倒计时取消、默认不导入、可选拍后接收、拍后进入相册保持连接及取景操作补跑UI／取景用例，均通过。普通屏、小屏、手势导航与身份确认检查已有本轮通过记录。真机拍摄与最新交互仍单独验收。

- Android：JVM单元测试、安装回归、取景横屏与菜单、数据库迁移、文件删除保护、客户记录和任务恢复

## 真机已取得的证据

2026-10-29红米Android13与A7C II的分版本结果见[真机记录](HARDWARE_ACCEPTANCE.md)。0.1.7构建8的全屏、取景与光圈恢复通过，构建9的最新照片倒序和自动加载仍需覆盖安装后复核。

2026-10-28，Xiaomi 17（25113PN0EC，Android17/API37）与Sony ILCE-7CM2（固件2.01）在共同路由器Wi-Fi上连接。已读取真实参数和1024×680 JPEG取景；取景参数中文映射与光圈写入／原值恢复取得读回结果。

0.1.4于13:06完成两项真机验收：99张相机索引、网格／大图选择同步、滑动选择两张、命名记录、图文单、下载5,993,880字节JPEG、断线隐藏列表及重连。已有三个原片摘要保持一致；横屏隐藏／显示玻璃菜单不改变窗口大小，光圈恢复至f/3.5并读回。验收截图与详细JSON仅留本机，未触发真实快门。

窗口修复前快门底部为2616px，手势安全线为2591px；0.1.4玻璃布局真机值为2486px。横屏覆盖2656×1220屏幕，系统无障碍矩形存在一个像素取整差。0.1.5继续调整竖屏与工具面板，不能直接沿用这些坐标作为新布局结果。

真实照片、数据库、诊断、密码和指纹均保存在本机忽略目录，不进入开源仓库。覆盖安装前已备份本机索引与配置，保留原有照片。相机卡不执行删除、格式化、固件或设置恢复操作。
