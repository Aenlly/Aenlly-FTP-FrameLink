# 实施与验收报告

版本：Android0.1.7／iOS0.1.6开发预览。Android、iOS、相机协议与本地选片的源码、软件测试和真机结果分别记录；本文件不代表已完成正式发布。

0.1.5增加系统相机式竖屏操作区、独立专业工具面板、已配对相机直接重连和失败回退设置；图库加入小／中／大图与列表，分别显示JPEG、RAW、HEIF及其导入状态。主取景页不常驻协议型号和分辨率，技术信息放入连接详情。两端使用新的相机／相片连接图标，来源与提示词见design/brand/ICON.md。

0.1.6升级编译与目标版本到Android17/API37，增加局域网权限流程。取景保持旋转时的同一窗口和菜单状态，横屏参数与快门分置两侧黑边，专业工具收为窄侧栏，直方图成为可关闭的角落参考图。图库采用5／3／2列与列表、蓝色圆勾，支持按当前范围全选、分页补齐和取消，修正重连后的空白列表，更新浮动导航。FTP增加复制配置、固定启动入口、登录状态与已接收照片入口。iOS提供需要自行签名的设备IPA，见ios/INSTALL.md。

## 本轮改动

Android0.1.7修正红米Android13全屏测量、相机目录先旧后新的分页和末页仍显示加载入口的问题。按当前日期先读取元数据快照，最新照片从第一页可见；滑到底自动补齐，结束与失败分开显示。iOS0.1.6未接入本轮目录加载改动。见[相机选片与加载](GALLERY_BROWSING.md)和[全屏兼容](ANDROID_13_FULLSCREEN.md)。

iOS原片以文件路径传过桥，导入和摘要以256KiB分块进行，预览采样解码。索引使用原子JSON保存，相机密码与受信任指纹使用Keychain。后台停止取景和FTP服务；运行中的任务在下次启动显示中断，避免假装后台仍在线。

Go FTP模块供iOS使用，Android继续使用原有Apache实现。接收只提供上传，唯一文件与回执落盘后回复成功；客户端支持被动模式、UTF-8、显式FTPS验证、上传临时文件与同名检查。标准FTP不能提供跨客户端的原子禁止覆盖，需服务器权限配合。

## 软件检查

完整日志位于本机忽略目录build-logs，冻结清单记录最终检查时间。失败尝试保留，不用截取日志末尾代替退出状态。

Android0.1.7取得JVM21项、安装回归31项、Go桥18项通过记录，增加250张照片的自动分页、稳定倒序、全选与末页检查，以及刚好100／200张时不产生虚假下一页的边界测试。iOS0.1.6保留Swift核心6项XCTest及14条核心检查、安装交互5项的既有通过记录；最终状态以冻结清单为准。

- Android：JVM单元测试、安装回归、取景横屏与菜单、数据库迁移、文件删除保护、客户记录和任务恢复
- Go：协议连接状态、身份握手、原片字节、FTP往返、同名与长度保护、不可信证书拒绝，并检查数据竞争
- iOS：原片导入／移除／恢复、客户记录独立、路径保护、滑动范围、FTP回执恢复与中断任务的核心测试；模拟器和设备架构分别构建，UI单独运行
- 界面：Android默认屏、小屏120%字体和手势导航；授权样片只用于模拟器，来源见[视觉记录](VISUAL_QA.md)
- 云端和网页：本轮未改业务源码，沿用先前11项服务端、5项网页队列和8项网页端到端结果；H2与本地私有文件不能代替MySQL/S3部署验收

最终数量与退出码以artifact-manifest.json及本机对应日志为准，不将上一版结果标成新版本真机通过。

本机JDK17.0.8曾在Kotlin UAST分析触发C1编译器错误。只对lint进程排除该方法的JIT后通过，未关闭规则或修改APK编译参数：

```sh
JAVA_TOOL_OPTIONS='-XX:CompileCommand=exclude,org.jetbrains.uast.kotlin.FirKotlinUastResolveProviderService::getArgumentForParameter' python3 scripts/check.py android-lint
```

## 真机已取得的证据

2026-10-29红米Android13与A7C II的分版本结果见[真机记录](HARDWARE_ACCEPTANCE.md)。0.1.7构建8的全屏、取景与光圈恢复通过，构建9的最新照片倒序和自动加载仍需覆盖安装后复核。

2026-10-28，Xiaomi 17（25113PN0EC，Android17/API37）与Sony ILCE-7CM2（固件2.01）在共同路由器Wi-Fi上连接。已读取真实参数和1024×680 JPEG取景；取景参数中文映射与光圈写入／原值恢复取得读回结果。

0.1.4于13:06完成两项真机验收：99张相机索引、网格／大图选择同步、滑动选择两张、命名记录、图文单、下载5,993,880字节JPEG、断线隐藏列表及重连。已有三个原片摘要保持一致；横屏隐藏／显示玻璃菜单不改变窗口大小，光圈恢复至f/3.5并读回。验收截图与详细JSON仅留本机，未触发真实快门。

窗口修复前快门底部为2616px，手势安全线为2591px；0.1.4玻璃布局真机值为2486px。横屏覆盖2656×1220屏幕，系统无障碍矩形存在一个像素取整差。0.1.5继续调整竖屏与工具面板，不能直接沿用这些坐标作为新布局结果。

真实照片、数据库、诊断、密码和指纹均保存在本机忽略目录，不进入开源仓库。覆盖安装前已备份本机索引与配置，保留原有照片。相机卡不执行删除、格式化、固件或设置恢复操作。
