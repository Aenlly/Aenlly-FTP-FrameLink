# iOS连接表单凭据隔离修正

2026-10-31，iOS0.1.8／build9。Android0.1.25及历史iOS0.1.7冻结文件保留，此次不重跑Android旧版整套验收，不操作实体设备或用户历史。

## 缺陷与修正

0.1.7相机和FTP连接表单的onChange依赖selectedProfile。选择A后取消保存会清掉这个标识，却为当前会话保留A的输入；随后改地址、端口、FTP的TLS或账号时，旧密码没有被清理。直接填写未保存凭据再改端点也有相同问题。这是源码可确定的缺陷，不是iPhone实测结论。

0.1.8改为字段Binding的用户编辑入口直接执行状态转换：

- 改相机地址或端口，清账号、密码、指纹和保存选择
- 改FTP地址、端口或TLS，清账号、密码和保存选择
- 改账号，清密码和保存选择
- 值没有变化时保留原输入；显式选择保存的B直接设置完整配置，不经过用户编辑入口，避免被异步onChange误清

保存簿、任务引用和Keychain结构没有变化；不迁移或删除现有照片。
