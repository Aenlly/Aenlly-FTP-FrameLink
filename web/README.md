# 摄影师工作台与客户选片网页

`npm install`后使用`npm run dev`，默认仅监听本机5177端口，代理本地8087云服务

客户访问`/s/{shareToken}`，输入6位访问码。编辑会串行保存，断网暂存当前设备，409版本冲突需要用户决定保留本机待保存项还是使用服务器结果。提交前等待所有自动保存结束

客户照片请求携带授权，通过私有资源接口加载。上传预览只接受JPEG/PNG；成片需要在客户选片确认后关联上传。云端不会自动公开本地原片

检查：`npm run build`、`npm test -- --run`。完整交互与视觉验证见`docs/IMPLEMENTATION.md`
