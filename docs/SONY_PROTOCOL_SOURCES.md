## 最小补采步骤

有对应机身后，先记录App／桥接提交、手机系统、机型、机身固件和网络连接方式。保持机身设置，首轮只采连接和读取，不拍照、不删除、不格式化、不恢复设置。

1. 保存GetDeviceInfo原载荷、Sony扩展握手版本与控制列表，区分机身广告能力和本App实现能力
2. 读取一次完整0x9209、几个代表属性的0x9251及0x9215；保留writable、Enabled、form、type与原始枚举，不只抄屏幕标签
3. 记录访问认证是否启用、认证方式和成功／失败阶段；不导出密码、私钥或含会话令牌的完整URL
4. 若机身允许，读取一页拍摄日期／卡内元数据、一组JPEG＋RAW缩略图及指定原片，保存长度与哈希；不调用0x9212进入会锁机身UI的传输模式
5. 对取景单独记录机身返回的URL结构、经过脱敏的响应头、原始JPEG尺寸及几帧延迟数据；不把存在URL属性等同于已取得可用画面
6. 原始载荷先只存本地，公开前移除Owner、序列号及会话令牌。脱敏版本单独标注为派生数据，并保留本地原件哈希
