# 相机选片与加载

相机内默认进入最近拍摄日期，最新照片在前。排序依据相机拍摄时间，导入时间不改变照片位置；后续页面只追加更早的照片。

## 操作约定

- 滑到列表末尾前自动读取下一页，读取中显示进度；全部读完显示“已加载全部”
- 读取失败停下来，提供重试；不会自动反复请求，也不把失败当作已经读完
- 全选作用于当前日期和筛选范围，包含尚未显示的页面；只补齐目录，不自动下载原片
- 网格、大图共用一份选择；小／中／大图为5／3／2列，另有列表模式
- RAW＋JPEG按一次拍摄合并，导入时分别选择格式；连拍分组可按需开启
- 断开后隐藏相机内列表，已导入原片继续可用；重连重新读取，不把缓存当作在线内容

## 为什么先读取目录

当前索尼适配器已验证的接口按时间向后读取。直接显示接口的第一页，会先出现早拍的照片，直到读完后才把最后拍的照片挪到前面。

Android0.1.7先读取所选日期的文件元数据，按拍摄时间倒序形成当前连接的列表快照，再每页显示100次拍摄。缩略图仍只在需要时获取，原片只有在确认导入后才下载。切换日期、刷新或重新连接都会重建快照。

不使用未经验证的相机逆序参数。目录较大时首屏需要等待，显示“正在读取相机照片”；后续可根据真实机型测量优化首屏时间。iOS0.1.6本轮保持原实现，尚未接入此加载改动。
