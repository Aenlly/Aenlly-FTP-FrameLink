# 无线取景清晰度

当前A7C II固件2.01的真机记录为1024×680 JPEG帧。这是实收尺寸；更高清的目标不限于1920×1080，需找到并验证机身实际提供的档位。

## 已核对

- 目前通道由alpha2go读取Sony属性0xD278中的取景URL，直接打开机身JPEG流，见`third_party/alpha2go/ptpip/sonyliveview.go`
- 该实现没有把图像宽度限制在1024，也没有在接收时缩小JPEG；单帧8MiB上限是传输长度保护，不是分辨率设置
- App按收到的像素绘制并保持完整比例，黑边来自屏幕与相机画幅比例不同；把控件放入黑边可以减少遮挡，不会提高源图细节
- 当前适配器尚未提供经过A7C II验证的预览尺寸切换；Android与iOS都不显示未经验证的“高清”档位

## 继续验证的入口

应核对机身原始能力描述和取景请求，确认是否存在可选尺寸，并记录切换前后JPEG头中的实际宽高、帧率与延迟。当前桥接层的参数列表只呈现已识别的安全属性，不能用“界面没有此参数”证明机身完全不支持。

Sony另有[网络视频流](https://helpguide.sony.net/ilc/2360/v1/en/contents/221h_network_streaming.html)和[HDMI输出](https://helpguide.sony.net/ilc/2360/v1/en/contents/0601_hdmi_resolution.html)文档，但它们属于不同通道与工作模式，不能直接作为当前拍照遥控取景更高清的证据。不同固件的可用功能仍需分开验证。

原片下载保持相机文件原始字节，不受取景帧尺寸影响。技术型号、固件与实收尺寸可在取景页“连接信息”中核对。
